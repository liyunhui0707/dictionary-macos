# Dictionary 0.6.0

This release improves **manual updates and rollback guidance**. The companion Chromium extension remains **0.2.1**.

- Check for Updates shows the installed version, chip family, release notes and validated DMG/ZIP links for that chip. Missing or ambiguous assets do not produce a guessed download link.
- Release and asset links must belong to this repository and the exact stable tag. Notes appear as bounded plain text; embedded Markdown is not executed or turned into additional links.
- A local build newer than the published stable release is identified separately, rather than reported as the current stable version or offered a routine downgrade.
- The update window and user guide explain retaining the previous installer and extension directory, replacing one App after quitting, checking the new version, and recovering a compatible earlier version.

## Install and update

Public downloads remain **ad-hoc signed and not notarized by Apple**. Read the release requirements and use the normal macOS first-open flow without disabling protections. Quit Dictionary before replacing it in Applications, retain the previous installer, and start the installed copy.

App and browser extension updates are separate. This release does not require replacing extension 0.2.1. Service preferences, credentials and pairing remain compatible; ad-hoc upgrades may require normal Accessibility consent. Do not routinely clear settings, keys, models or permissions.

There is no background version check, automatic download, installer or automatic rollback. Opening Check for Updates or pressing its check button reads GitHub's public stable-release metadata. Downloads are user-initiated in the browser. Checksums establish file integrity, not developer identity.

## Validation and limits

382 Swift tests and 126 Node tests passed, including strict asset/tag/address checks, chip selection, missing/duplicate assets, bounded notes, cancellation and out-of-order responses. Synthetic light/dark previews cover available, current, ahead and missing-Intel-package states.

Local native acceptance read the actual published 0.5.0 metadata, checked its Apple Silicon DMG/ZIP/checksum URLs, expanded/collapsed notes, scrolled the recovery guide, reopened and closed the window, and restored the daily App. It did not click a download, call a model or change permissions. Intel/Rosetta selection is covered by controlled tests, not physical Intel acceptance.

This batch does not change contextual capture, local models or explanation prompts. Existing quality limits remain documented in [quality validation](../quality.md).

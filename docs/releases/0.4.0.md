# Dictionary 0.4.0

This release guides a new user from service selection to a contextual lookup in a reading app. The bundled Chromium extension remains **0.2.1**.

- **Getting Started** now distinguishes configuration, an actual response containing a source sentence, and your explicit check of the sentence and meaning. Saving settings, checking a model or exporting an extension does not count as a successful lookup.
- Missing context, empty meanings, echoed target words, failed requests and cancellation do not complete the check. Changing the primary service clears old progress. Progress stays within the current App session; restarting retains service settings but starts a new check.
- Local setup explains how to recover when Ollama is unavailable or the selected model is missing. The App does not install services or download models automatically. Preparing the manual example neither submits a query nor overwrites existing input.
- Browser and native reading instructions are shown separately. The website provides selectable synthetic passages and answer hints; actual results still come from the installed App and extension.

## Install and update

Choose the asset matching your Mac. The download is **ad-hoc signed and not notarized by Apple**. Follow the normal macOS first-open flow without disabling security protections. Quit Dictionary before replacing it in Applications, and retain the previous download for rollback.

No API key or local model is bundled. DeepSeek requires your own key and usage allowance; Ollama requires a separately installed service and model. Existing extension 0.2.1 and pairing configuration remain compatible; this App update does not require replacing an already working extension. Updates remain manual.

## Validation and limits

On the maintainer's Mac, a fresh isolated App configuration started without a selected service. A manual river example returned the matching sentence and “河岸”. Owner-operated TextEdit shortcuts returned matching river and finance sentences and meanings. Explicit confirmation then completed the guidance. Restarting the same configuration retained local service selection, reset session progress and preserved existing capture permission.

Controlled tests separately cover missing services, unavailable meanings, cancellation and late-result handling. These are not claims of live failure testing. This round used an existing local model environment, not a clean macOS account, model installation, cloud account or new browser pairing. Cross-Mac acceptance was not repeated in this round.

The default local model still has known meaning errors for some collocations and grammatical words. A model response is not proof of accuracy, and this release does not claim support for every app or document.

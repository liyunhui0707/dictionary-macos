# Dictionary 0.2.0

This delivery adds a choice of primary lookup service and a clearer setup path.
Choose DeepSeek with your own API key, or use Ollama on your Mac. Cloud queries
require an explicit data/usage-cost confirmation; saving a key alone does not
switch the primary service. Failed requests never silently switch services.

- First-use guidance and a persistent service choice in Settings.
- Contextual DeepSeek lookup, with ordinary dictionary lookup when no context is available.
- Source labels in the main window and popup. Switching services cancels old work.
- Explicit stable-version checking through GitHub Releases, with manual download/replacement.
- Architecture-specific ZIP/DMG packaging with notices, checksums and public provenance.

## Installation and updates

The selected download channel uses **ad-hoc signing and is not notarized by Apple**.
First opening may require your confirmation in macOS Privacy & Security. No API
key, Ollama installation, local model or system permission is bundled.
See the [installation guide](../guide.md#安装与首次打开).

Choose the matching CPU architecture from the assets actually listed in the release.
Quit Dictionary before replacing it in Applications. Keep the previous package
for rollback. Settings and Keychain format remain compatible; ad-hoc signing does
not guarantee Accessibility consent continuity between versions. Do not routinely
reset permissions. There is no background download or automatic installer.

## Validation scope

The final DeepSeek production-provider candidate met the 24-case synthetic
regression rubric, with a median response time of 1.04 seconds in that run.
This is not an accuracy estimate for arbitrary text or proof of universal app support.
The existing default local model's known semantic weaknesses remain documented
in [quality validation](../quality.md).

Local native first-use, service selection, a contextual bank lookup and version
checking were exercised. Final per-artifact cross-Mac results and tested OS/CPU
belong in the published release record. Source push and packaging alone do not
establish installation acceptance.

Books, browsers and other apps differ in text access. Readest, Session Manager
and Markdown do not yet have a full contextual-capture acceptance claim in this
delivery. Missing context is identified rather than presented as a verified sentence.

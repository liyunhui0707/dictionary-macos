# Dictionary 0.5.0

This release adds **Diagnostics & Feedback**, available from the application menu, menu-bar menu and Settings. The bundled Chromium extension remains **0.2.1**.

- View the current lookup service, last explicit local model check, native shortcut registration, local extension listener and recent primary lookup or capture attempt. Recovery suggestions distinguish service configuration, connection, authentication, account/rate limits, missing context and unusable responses.
- Authenticated connection checks are recorded as events seen during this App session, not proof that a browser is currently connected or a shortcut is bound. No background model checks or automatic recovery requests are added.
- Preview a fixed-field diagnostic snapshot before saving it as a text file. The report excludes selected words, surrounding text, model answers, credentials, tokens, personal paths, document/app identities and machine information. It is never uploaded automatically.
- A privacy-guided GitHub issue form helps users provide reproduction steps. Opening the page does not submit a report. Standalone “Ask DeepSeek” assistance remains in its original result window; it is separate from primary-lookup diagnostics.

## Install and update

Choose the asset matching your Mac. Public downloads remain **ad-hoc signed and not notarized by Apple**. Use the normal macOS first-open flow without disabling protections. Quit Dictionary before replacing it in Applications and retain the previous download for rollback.

Existing service preferences, credential storage, pairing protocol and extension 0.2.1 remain compatible. No model, API key or system permission is bundled. Updates remain manual.

## Validation and limits

Automated checks cover report field allowlisting and private-data exclusion, typed failure categories, authenticated status requests, cancellation, stale results and real local listener readiness/port conflicts. Hidden synthetic previews cover light/dark settings and the report window. These do not establish semantic accuracy or universal reading-app support.

Local macOS acceptance covered the menu entry, first report preview, cancelling a save, saving the actual text file and reopening a fresh preview. The saved report matched its fixed-field schema. The previous daily App was restored after testing; no model requests, new permissions or remote-machine tests were used for this batch.

This batch does not change local models, prompts or translation behavior. Known local-model meaning errors remain documented in [quality validation](../quality.md).

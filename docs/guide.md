# 使用指南

## 安装与首次打开

从本项目 GitHub Releases 选择与你的 Mac 芯片相符的 DMG 或 ZIP；源码归档不是安装包。
DMG 打开后将 Dictionary 拖到 Applications，ZIP 解压后将应用移入“应用程序”，再从那里启动。
保持一个日常安装入口，关闭其他测试副本。

当前公开渠道使用临时签名，未获 Apple 公证。首次打开可能被系统阻止。
仅在确认来源可信时，按 [Apple 的说明](https://support.apple.com/102445) 在尝试打开后，
进入“系统设置 → 隐私与安全”选择“仍要打开”，并由你完成系统验证。
不需要关闭 Gatekeeper、移除隔离属性或更改整个系统的安全策略。受组织管理的 Mac 可能不允许此操作。
SHA256SUMS 可用于核对下载完整性，但不是开发者身份认证。

## 选择查词服务

首次启动点击“设置查词方式”；以后可从侧栏的当前服务或“偏好设置 → 查词服务”更改。

- **DeepSeek 云端**：在同页保存自己的 API 密钥，勾选文字发送及费用确认，再点“使用 DeepSeek 查词”。
  不需要 Ollama 或本地模型；需要网络、有效密钥及服务商可用额度。保存密钥不代表已验证 API。
- **Ollama 本地**：安装并运行 Ollama、准备模型，再点“使用本地查词”。模型不包含在安装包内。
  查词语境发送到本机服务；可另外开启 DeepSeek 作为主动询问的第二来源。

更改主服务会取消当前查词并清除旧结果；不会暗中改用另一个服务。
关闭或移除正在使用的 DeepSeek 密钥后，需要重新启用或选择本地模式。

## 查词

主窗口支持英文单词、短语和句子。展开“添加语境”补充原句，点击“查词”或按 ⌘Return。
Return 换行，输入法候选确认不会提交。查询中可以取消；新查询会替代同通道的旧请求。

阅读时选中英文并按 ⌥D。弹窗可以固定、关闭；选词结果与主窗口草稿分别保存于当前会话。
不要同时运行两个 Dictionary，否则快捷键和本机服务端口可能冲突。

## 模型与云端

安装并启动 Ollama，准备 `qwen2.5:7b` 或自行评估的本地模型。在偏好设置检查模型列表、
选择已安装的模型并保存，下次启动生效。检查不会下载模型，也不验证翻译质量。
连接失败时先检查 Ollama 是否运行、模型是否存在，不要因此反复修改选词权限。

本地模式的云端辅助使用用户自己的 DeepSeek API 密钥。保存并启用后，在已完成的查询上点击“询问 DeepSeek”。
保存只验证钥匙串写入，不会自动发送测试文字。可以关闭 DeepSeek 或移除本应用保存的密钥；
移除本地密钥不会在服务商处撤销它。

## Chromium 浏览器

打开扩展管理页，启用开发者模式，选择“加载已解压的扩展”，指向 `extensions/chromium`。
保持 Dictionary 运行，从其菜单栏菜单选择“Copy extension token”，粘贴到扩展选项并验证保存。
验证会向本机服务发送合成的 ping 查询。然后在普通网页选词并按 ⌥D。
浏览器内部页面、扩展商店和部分受保护页面不能注入脚本。

## Safari

在 Safari 的高级设置显示开发功能，并在开发菜单允许来自 Apple Events 的 JavaScript。
首次查词时，按系统提示允许 Dictionary 自动化 Safari。没有这些配置时，可能仅获得选词。
不要为了查词关闭系统安全保护。

## Obsidian

使用 Obsidian 1.11.4 或以上桌面版。把 `extensions/obsidian/main.js` 与 `manifest.json`
放入目标 Vault 的 `.obsidian/plugins/dictionary-lookup/`，按 Obsidian 的方式启用插件。
在插件设置配置本机令牌；编辑区和阅读区通过插件执行查词。移动端不支持此桌面连接。

## 语境不足与错误释义

检查弹窗展示的单词是否与选区一致，展开捕获的语境检查是否对应当前段落。
缺少语境时，可在主窗口粘贴原句补充查询。页面片段、重复词或选区证据不可靠时，
应用可能只查询单词。AI 仍可能误判词性和词义，请结合英文参考核对。

## 更新与回退

“Dictionary → 检查更新”只查询公开稳定发行版；若 GitHub 暂时不可达，可稍后重试或直接打开下载页。
下载更新前退出 Dictionary，保留上一版安装包，再替换“应用程序”中的应用并重新打开。
查词服务选择、模型选择与钥匙串密钥通常保留；临时签名跨版本的选词授权连续性不保证，
只有当前运行版本确实未获授权时才按系统提示处理，不要例行重置权限。
回退同样先退出再替换旧包；0.2.0 没有改写旧版钥匙串项目或扩展令牌格式。
当前没有后台下载或自动安装更新。

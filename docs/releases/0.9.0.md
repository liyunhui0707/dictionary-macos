# Dictionary 0.9.0 — local candidate

This candidate combines context capture, reading setup and an optional local-model profile.
It remains **unpublished**. Installation upgrades and the final Books cases have been checked on two Macs,
with an OCR reliability concern retained below. The Chromium extension remains **0.2.1**.

## Changes

- Books screen context can distinguish repeated words on the same line using each OCR word's source range and bounding box. The pointer must identify one occurrence; ambiguous or incomplete evidence is still rejected. Recognition failure, timeout and empty output have distinct diagnostics. OCR remains optional and requires preview confirmation before querying.
- Getting Started offers separate browser, Books and native reading paths. Returning from General keeps the selected reading path in the same settings window. Browser setup adds an explicit pairing-token copy button; opening settings does not copy a token or prove browser connection.
- Selecting the exact installed model `qwen3.5:9b-q4_K_M` enables the compared contextual task for supplied sentences, with constrained JSON, temperature 0 and thinking disabled. Other model tags keep their existing tasks. The default remains `qwen2.5:7b`; no model is bundled, downloaded or selected automatically.
- Contextual results focus on the primary AI meaning and sentence translation, retaining the separately labelled English dictionary reference. General AI literal/alternative meanings remain available for word-only queries. Raw answers are preserved; this display change does not repair model errors.

## Development validation

The complete software regression passed **435 Swift tests in 58 suites** and **127 Node tests**.
Subsequent focused checks passed 32 UI/model-setting tests, including a new no-automatic-model-switch case,
and five evaluation-framing tests. These counts describe separate runs, not a summed test total.
Synthetic settings rendering fits the existing native layout; opening settings does not access credentials or query a model.

The owner confirmed the same-line second `bank` in Books: the preview and confirmed result retained
`Later, they rested on the bank of the river.` and the contextual meaning “河岸”.
Readest's long-chapter `observations` original was also confirmed after scrolling.
These checks used fixed development Testing builds, not this final archive.
Subsequent candidate-level checks on the second Mac are recorded separately below.

Two single-round local-model comparisons recorded 16 responses each: the fixed acceptance set with synthetic exact selection,
then an independent set with inferred sentence evidence. Median response times were 2.83 and 2.70 seconds on the test machine.
Collocations, existential subjects and unknown labels improved, but **the raw answers did not pass every semantic criterion**:
one contextual alternative was unrelated, a stream-bank sentence translation omitted the bank, and some glosses remained broad.
There is no general accuracy or cross-device performance guarantee. See [quality evidence](../quality.md).

## Candidate installation and Books acceptance

Both Apple Silicon Macs running macOS 27.2.1 completed the 0.8.0 → 0.9.0 upgrade and normal restart,
preserving the selected service and model. Previous-version ZIP archives were verified for rollback.
The second Mac used the exact public candidate from `89fcd4b`; the local daily build used the same source
with its existing signing identity preserved. They are distinct binaries.

On each Mac, the owner confirmed the second `bank` in the repeated-word chapter with the river original and “河岸”,
preview abandonment followed by confirmation, then the finance page with the deposit original and “银行”.
The final shared-screen result on the second Mac also showed the deposit original. Normal system consent there
restarted the process and did not retain the original per-attempt log; no OCR timing is claimed for that Mac.

Local metadata recorded two screen previews and a successful inferred native deposit sentence.
The same session also contains two recognition timeouts, with total capture durations of 3417 and 3340 milliseconds,
and conservative source-change fallbacks. Setup and owner attempts were not separated by a recorded event boundary.
The final two cases therefore do **not** establish first-attempt reliability or an entirely failure-free Books run.
The cause of these timeouts remains unisolated; see [the detailed acceptance record](../reading-compatibility.md).
Both daily apps were restored to normal launch with batch logging disabled.

A subsequent development patch coordinates OCR's former fixed three-second timeout with the
remaining capture validity window and adds numeric recognition timing diagnostics. Controlled
boundary tests pass, but in-memory recognition measurements did not reproduce the slow case.
This patch is **not included in the frozen `89fcd4b` candidate or the daily installations from that batch**;
it does not retroactively change the candidate's acceptance result.
Local fixed-Testing acceptance confirmed repeated-word preview abandonment/confirmation and the
finance original. Two OCR attempts received 4.762/4.861-second budgets and completed recognition
in 237/78 milliseconds; the finance case used native text. No timeout occurred in these three
captured attempts. The original daily binary was restored; the slow recognition case remains unisolated.
The budget patch is being prepared separately as [the 0.9.1 local candidate](0.9.1.md).

## Package and remaining acceptance status

The candidate uses the existing **ad-hoc signed, unnotarized** channel for **Apple Silicon / macOS 14 or later**.
Its public manifest identifies the source commit and package hashes. Building and inspecting the local artifacts
does not by itself establish successful installation or reading capture. The scoped installation and Books evidence
above is separate from package inspection. Browser-download first opening, a fresh missing-service recovery run and
complete browser pairing were not performed in this batch. OCR reliability and the remaining acceptance scope
must be considered before any public delivery decision.

Normal macOS consent is required. Preserve the previous installer for manual rollback and keep the same daily installation path.
Do not reset permissions as an update step. Models, API keys, local profiles and private acceptance logs are excluded.
Updates remain manual; updating the App does not replace an extension already loaded by a browser.
Reading support remains scoped to the evidence in [reading compatibility](../reading-compatibility.md), not arbitrary applications.

# Dictionary 0.7.0

This release improves reading capture and adds optional **local screen context for Apple Books**. The Chromium extension remains **0.2.1**.

- Markdown editing views can recover a sentence when an editor's numeric range disagrees with its text representation. The native text-marker endpoints must belong to the focused editor, remain stable, and agree with an independent copy of the selected word.
- Books keeps a usable native sentence first. When it cannot provide a sentence, users can opt into local screen text recognition in Settings → General. The option is off by default and requires macOS Screen Recording permission for the installed App.
- Only the current Books window is captured, with a nearby region processed in memory by Vision. Images are not saved or uploaded. Source, window, pointer and pixels are checked across the capture; uncertain evidence is discarded rather than assigned to a guessed occurrence.
- Recognized text appears in a review panel before a lookup. Confirm to use it with the selected service, or discard it without sending that screen context. Cloud mode sends the confirmed word and text; it does not send images.

## Install and update

Public packages are **ad-hoc signed and not notarized by Apple**, for **Apple Silicon / macOS 14 or later**. Use the normal macOS first-open flow; do not disable system protections. Quit the previous App, retain its installer for rollback, and replace the single Applications copy. The minimum OS declaration is not a claim that every macOS version was physically tested.

Models and API keys are not included. Existing service preferences and browser pairing remain compatible; extension 0.2.1 does not need replacement. Normal macOS consent may be required for an ad-hoc upgrade. Accessibility and optional Screen Recording permissions are separate; neither is routinely reset by the updater. Updates and rollback remain manual.

## Validation and limits

409 Swift tests and 126 Node tests passed during development, including source stability, native capture regressions, preview confirmation and cancellation, local crop geometry, and Vision recognition of synthetic in-memory text images. Final candidate packaging and installation checks are recorded with the release.

Local synthetic acceptance covered Markdown's river, finance and repeated-word editing cases, Readest's long chapter, and Books screen-context preview, discard and confirmed lookup. Captures remain heuristic when they do not establish an exact native range. See [reading compatibility](../reading-compatibility.md) for the actual scope and evidence.

Initial screen recognition can be unavailable or time out, in which case the original native word or paragraph is retained. Same-line repeats, uncertain pointer locations, unusual columns and partial sentences may decline screen context. This release does not guarantee context capture in every app or book, change local models, or resolve the known interpretation errors described in [quality validation](../quality.md).

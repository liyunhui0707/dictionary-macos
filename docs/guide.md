# 使用指南

## 安装与首次打开

从本项目 GitHub Releases 选择与你的 Mac 芯片相符的 DMG 或 ZIP；源码归档不是安装包。
DMG 打开后将 Dictionary 拖到 Applications，ZIP 解压后将应用移入“应用程序”，再从那里启动。
保持一个日常安装入口，关闭其他测试副本。

当前公开渠道使用临时签名，未获 Apple 公证。首次打开可能被系统阻止。
仅在确认来源可信时，按 [Apple 的说明](https://support.apple.com/102445) 在尝试打开后，
进入“系统设置 → 隐私与安全”选择“仍要打开”，并由你完成系统验证。
不需要关闭 Gatekeeper、移除隔离属性或更改整个系统的安全策略。受组织管理的 Mac 可能不允许此操作。
SHA256SUMS 可用于核对下载完整性，但不是开发者身份认证。

## 选择查词服务

0.3.0 起可从侧栏或“Dictionary → 开始使用”查看服务、阅读软件接入和合成样例指引。
首次启动点击“开始设置与首查”，按“开始使用”的提示继续；以后可从侧栏的当前服务或“偏好设置 → 查词服务”更改。

- **DeepSeek 云端**：在同页保存自己的 API 密钥，勾选文字发送及费用确认，再点“使用 DeepSeek 查词”。
  不需要 Ollama 或本地模型；需要网络、有效密钥及服务商可用额度。保存密钥不代表已验证 API。
- **Ollama 本地**：安装并运行 Ollama、准备模型，再点“使用本地查词”。模型不包含在安装包内。
  查词语境发送到本机服务；可另外开启 DeepSeek 作为主动询问的第二来源。

更改主服务会取消当前查词并清除旧结果；不会暗中改用另一个服务。
关闭或移除正在使用的 DeepSeek 密钥后，需要重新启用或选择本地模式。

## 查词

主窗口支持英文单词、短语和句子。展开“添加语境”补充原句，点击“查词”或按 ⌘Return。
Return 换行，输入法候选确认不会提交。查询中可以取消；新查询会替代同通道的旧请求。

阅读时选中英文并按 ⌥D。弹窗可以固定、关闭；选词结果与主窗口草稿分别保存于当前会话。
不要同时运行两个 Dictionary，否则快捷键和本机服务端口可能冲突。

## 模型与云端

安装并启动 Ollama，准备 `qwen2.5:7b` 或自行评估的本地模型。在偏好设置检查模型列表、
选择已安装的模型并保存，下次启动生效。检查不会下载模型，也不验证翻译质量。
连接失败时先检查 Ollama 是否运行、模型是否存在，不要因此反复修改选词权限。

本地服务未连接时，设置页提供 [Ollama 官方下载页](https://ollama.com/download/mac)。
已经安装时先打开 Ollama，再点击“检查连接”。缺少默认模型时，可以在终端自行执行：

```sh
ollama pull qwen2.5:7b
```

这是模型下载命令，需要网络和数 GB 磁盘空间，不会由 Dictionary 自动执行。
用法见 [Ollama CLI 说明](https://docs.ollama.com/cli)，模型信息见 [官方模型页](https://ollama.com/library/qwen2.5:7b)。
下载完成后重新检查，或选择其他已安装模型；保存模型选择后重新打开 Dictionary 生效。
默认本地模型在部分搭配、语法词和未知词中仍有已知误译，安装成功不代表质量验证通过。
质量优先时可自行选择 DeepSeek，但仍需核对结果，并接受语境发送及 API 用量费用。

本地模式的云端辅助使用用户自己的 DeepSeek API 密钥。保存并启用后，在已完成的查询上点击“询问 DeepSeek”。
保存只验证钥匙串写入，不会自动发送测试文字。可以关闭 DeepSeek 或移除本应用保存的密钥；
移除本地密钥不会在服务商处撤销它。

## Chromium 浏览器

0.3.0 起的完整 App 自带配套扩展，无需安装开发工具或下载整个源码仓库。
在“开始使用”点击“导出配套浏览器扩展”，选择一个长期保留的位置。
然后打开浏览器扩展管理页，启用开发者模式，选择“加载已解压的扩展”，
指向导出的 `Dictionary Browser Extension` 文件夹。源码运行时也可直接加载 `extensions/chromium`。
0.2.0 App 没有此导出入口，使用对应版本的源码扩展；不要混用需要新版状态接口的扩展。
保持 Dictionary 运行，从其菜单栏菜单选择“Copy extension token”，粘贴到扩展选项并验证保存。
0.2.0 起的扩展使用独立的连接检查，不调用模型、不消耗云端查询额度，也不显示已保存的令牌。
它需要配套的新版 App；提示版本较旧时先更新 App，不要反复修改系统权限。
然后在普通网页选词并按 ⌥D。
浏览器内部页面、扩展商店和部分受保护页面不能注入脚本。
扩展 0.2.1 会读取当前焦点中的同源阅读框，不回用主页遗留的选区；跨域或受限框架请在主窗口手动补充语境。
切换标签页或刷新会停止尚未提交的旧捕获；已经提交的查询仍可在 Dictionary 中取消。

没有弹窗时，点击扩展图标：先看实际快捷键是否已绑定，再点击“检查连接”。
选中网页单词后也可点击“查询当前选词”，区分快捷键与连接问题。
检查连接只验证扩展与 App 的认证链路，不代表模型可用或释义准确。
更新扩展后建议刷新原网页。若页面查词组件未连接，扩展会仅在原标签页补接一次；浏览器拒绝访问时停止，不自行改权限。
错误提示中的 `CAPTURE_NO_RECEIVER` 表示页面组件未连接，`CAPTURE_ACCESS_DENIED` 表示浏览器未允许访问。
解压缩扩展应一直保存在固定目录，不要继续加载旧仓库或临时构建中的副本。
同一时间只启用一个 Dictionary Lookup，并只运行一个 Dictionary App。
导出不会覆盖已有目录，也不会包含浏览器设置或令牌。更新时先保留旧目录，
将新版导出到另一个位置；验证新扩展后停用旧项。不要仅替换 App 就假定扩展也已经更新。

## 首次查询自测

“开始使用”分别显示服务配置、主窗口查询与阅读软件查询的实际进度，并提示下一步。
选择服务、保存密钥、检查模型、导出扩展都不会自动记为查词成功，也不会自动发起翻译。

“开始使用 → 在主窗口准备样例”会填入 `bank` 和 `They walked along the bank of the river.`，
不会自动提交。已有输入或正在查询时不会覆盖。由你主动点击“查词”；云端模式按服务商用量计费。
检查释义是否适用于河流句。随后还需在自己的阅读软件中选词并按 ⌥D，核对浮窗原句，
因为主窗口手动查询成功不能证明选词、浏览器扩展或语境获取成功。

浏览器接入步骤在“我主要在 Chrome、Edge 或 Brave 中阅读”下展开。
完成配对后，可打开 [阅读查词样例](https://dictionary-macos-liyunhui.outerepoch3.chatgpt.site/reading-check.html)，
分别查询河流和存款句中的 `bank`，检查实际浮窗的原句与词义；该页面不模拟查词结果。
它还提供搭配和语法词检查，帮助区分“抓到了原句”和“解释正确”。

收到含原句的释义后，回到“开始使用”亲自确认原句和词义是否对应。
缺原句、空释义、失败和取消不会记为完成；切换服务后需要重新自测。
“本次首查自测已完成”只表示你核对过这一项阅读场景，不代表所有软件或全部词义均通过。
进度不保存正文或密钥，仅在本次 App 会话内保留；重新打开 App 后重新开始。

## 问题诊断与反馈

从应用菜单或菜单栏图标菜单选择“诊断与反馈…”，也可进入“偏好设置 → 问题反馈”。
页面分别显示当前查词方式、最近一次主动模型检查、本机扩展连接服务和最近主查词或选词尝试的状态。
单独“询问 DeepSeek”的辅助结果仍在原查询窗口查看，不包含在主查词诊断中。
打开页面不会调用模型、检查网络或读取密钥；“检查本地服务与模型”只在主动点击时请求本机模型列表。

- 没有弹窗：扩展面板检查实际快捷键、连接和站点访问；原生软件查看当前 App 的选词权限。
- 有弹窗但服务失败：按错误类别检查服务、模型、认证或账户额度，不自动切换服务或重试。
- 缺少或不对应的原句：先重新选词或补充语境；原句正确但词义错误时，再考虑解释服务或模型能力。

认证检查记录只证明本次曾收到有效请求，不代表浏览器当前在线、已绑定快捷键或当前网页可访问。
模型列表检查结果也不是持续健康监测或释义质量验证。

选择“预览诊断报告…”可查看固定字段快照，再选择“保存文本…”。报告不含选词、正文、模型回答、
密钥、令牌、个人路径或机器信息，不保存完整操作历史；重新打开 App 后重新记录。
到 GitHub 反馈时由你自行填写、附带报告并提交。使用合成例句复现，截图先遮住私人内容；
不要把私人书籍、聊天或原始模型日志直接提交到公开问题区。

## Safari

在 Safari 的高级设置显示开发功能，并在开发菜单允许来自 Apple Events 的 JavaScript。
首次查词时，按系统提示允许 Dictionary 自动化 Safari。没有这些配置时，可能仅获得选词。
不要为了查词关闭系统安全保护。

## Obsidian

使用 Obsidian 1.11.4 或以上桌面版。把 `extensions/obsidian/main.js` 与 `manifest.json`
放入目标 Vault 的 `.obsidian/plugins/dictionary-lookup/`，按 Obsidian 的方式启用插件。
在插件设置配置本机令牌；编辑区和阅读区通过插件执行查词。移动端不支持此桌面连接。

## 语境不足与错误释义

检查弹窗展示的单词是否与选区一致，展开捕获的语境检查是否对应当前段落。
缺少语境时，可在主窗口粘贴原句补充查询。页面片段、重复词或选区证据不可靠时，
应用可能只查询单词。AI 仍可能误判词性和词义，请结合英文参考核对。

## 更新与回退

“Dictionary → 检查更新”主动读取 GitHub 的公开稳定版，显示本机版本、芯片类别、版本说明与可确认的安装包。
没有对应芯片的包时会提示；本机构建高于公开稳定版时单独说明，不把它误报为已是稳定版或推荐降级。
若 GitHub 暂时不可达，可稍后重试或打开“全部版本与回退下载”。App 不会后台检查、下载或自动安装。

1. 更新前记下当前版本、查词方式和模型选择，保留旧安装包与已加载的扩展目录。阅读新版的系统要求、签名与公证说明。
2. 通过匹配芯片的 DMG 或 ZIP 下载新版。退出 Dictionary，再替换“应用程序”中的 App，并从那里启动；不要从多个副本启动。
3. 在“关于 Dictionary”核对版本，并用“开始使用”的样例检查原句与释义。App 与浏览器扩展分别更新；扩展有变化时按上面的 Chromium 指南导出、加载新版，保留旧目录以便恢复。
4. 新版有问题时先打开“诊断与反馈”。需要回退则退出新版，在“全部版本”找到先前使用的版本，阅读兼容说明，再用适合芯片的旧安装包按相同方式替换；扩展也恢复到与该 App 配套的版本。

查词服务、模型选择和钥匙串密钥通常保留；回退前应确认目标版本是否兼容当前设置。
不要为更新清空设置、钥匙串密钥或模型。临时签名跨版本的选词授权连续性不保证，
只有当前运行版本确实未获授权时才按系统提示处理，不要例行重置权限。
下载校验值可核对文件完整性，但不能证明开发者身份或替代 Apple 公证。

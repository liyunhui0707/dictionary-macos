# Dictionary 0.8.0

This release simplifies first-use setup. The Chromium extension remains **0.2.1**.

- Getting Started can prepare the bundled browser extension in a fixed, versioned folder with one click. The folder can be revealed or its path copied; choosing another parent folder remains available.
- Existing extension files are reused only after verification against this App's bundled files. Conflicting files are left untouched, and older version folders remain available for rollback.
- The last prepared folder is checked again after restart. Prepared files do not imply browser pairing or a successful reading lookup; those steps remain explicit.
- A bundled synthetic reading page is available through the local App connection. Opening it does not read a pairing token or invoke a model. It provides river and finance sentences for checking selection and contextual meaning.

## Install and update

Packages use the existing **ad-hoc signed, unnotarized** channel for **Apple Silicon / macOS 14 or later**. Models and API keys are not included. Keep one Applications copy and preserve the previous installer for manual rollback. Use normal macOS consent; do not disable security protections or reset permissions as an update step.

Browser extension 0.2.1 remains compatible. Updating the App does not replace an extension already loaded in a browser. Existing service preferences and browser pairing remain separate from the extension folder record. First-use query confirmation is session state and is checked again when appropriate.

## Validation and limits

Development regression passed 420 Swift tests and 127 Node tests, including extension validation, versioned folder reuse, local sample routing, package resource checks, and first-use state. Synthetic native previews cover fresh, prepared and changed-folder states in light and dark appearance.

Local synthetic acceptance passed with a fresh App configuration: service selection, installed-model check, a contextual main-window query, extension preparation, directory reveal and path copy, cancellation, restart verification and existing-folder reuse. The owner confirmed correct river and finance originals and meanings in TextEdit; metadata independently recorded anchored captures and successful local responses. The daily App was restored after testing.

An isolated Edge profile loaded the prepared extension and the real App's bundled sample. Unpaired state, rejected invalid pairing, saved synthetic pairing and the two submitted original sentences passed. Pairing and translation HTTP responses were mocked in that browser test; it does not establish real-browser model quality or a physical shortcut result.

The exact candidate was installed from 0.7.0 on another Apple Silicon Mac running macOS 27.2.1. Settings, installed payloads, prepared extension files and rollback were checked; the owner confirmed the contextual main-window result and missing-service recovery. This transfer used SCP. Browser-download quarantine first-open, new system-permission grants and native reading capture on that second Mac were not tested in this batch.

Reading capture and interpretation retain the limits documented in [reading compatibility](../reading-compatibility.md) and [quality validation](../quality.md). This release does not change local model quality or promise context capture in every application.

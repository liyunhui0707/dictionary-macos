# Dictionary 0.3.1

This maintenance release improves browser selection and context capture, with Chromium extension **0.2.1** bundled in the App.

- Chromium and Safari follow focus into accessible same-origin reading frames, instead of returning an old selection from the parent page. Repeated words and styled text keep their original source positions.
- Restricted, cross-origin or excessively nested frames stop capture rather than reusing another document's context. Extension permissions are unchanged.
- The shortcut uses the browser-provided source tab. If an already-open page has no live extension receiver, reconnect its top-frame script once using existing permissions. Browser denials stop capture and show a specific error; no permissions are changed.
- Before submitting a browser lookup, the extension checks the active tab, window and page address. A new lookup, tab/window switch or reload invalidates pending capture. This does not cancel a model request already submitted to Dictionary.
- Dictionary opening its result window is not reported as a cancelled lookup. Reloading an unrelated background tab does not discard the current capture.

## Install and update

Choose the asset matching your Mac. The download is **ad-hoc signed and not notarized by Apple**; follow the normal macOS first-open flow without disabling protections. Quit Dictionary before replacing it in Applications and retain the previous download for rollback.

Export extension 0.2.1 from **Getting Started** to a permanent folder, then update the browser's unpacked extension and refresh existing pages. Replacing the App alone does not update an already loaded extension. Enable one Dictionary Lookup at a time. Pairing tokens, service preferences and credential formats are unchanged; no API key, model or system permission is bundled. Updates remain manual.

## Validation scope

Automated checks exercise both deployed DOM paths, original UTF-16 positions, repeated words, styled and reverse selections, nested readers, sandbox isolation, stale focus and asynchronous browser-source changes. Existing native capture, provider lifecycle, export and packaging regressions also pass.

Real-browser acceptance and installation checks for the final candidate are recorded in [reading compatibility](../reading-compatibility.md). These checks do not establish support for every website, book, editing view or AI meaning; see [quality validation](../quality.md).

# Dictionary 0.3.0

This version brings setup instructions and the matching browser extension into the App,
and improves source/context capture in common reading applications.

- **Getting Started** brings together lookup-service selection, native selection access,
  browser setup, troubleshooting, and a synthetic contextual lookup sample.
- The App includes Chromium extension **0.2.0**. Export it to a permanent folder;
  a source checkout or developer tools are not required. Export refuses to overwrite
  an existing directory and does not copy browser settings or pairing tokens.
- The extension shows its actual shortcut and authenticated local connection status.
  Its toolbar lookup provides an alternative to the shortcut. Pairing verification
  no longer queries a model or treats an arbitrary server response as success.
- Native capture stays bound to the application that initiated the lookup. Source
  changes cancel capture; Readest can use bounded WebKit sentence evidence instead
  of scanning an entire long chapter. Uncertain context remains labelled as inferred.

## Install, upgrade and rollback

The download is **ad-hoc signed and not notarized by Apple**. Follow the normal
macOS first-open confirmation; do not disable system protections. Choose an asset
for your Mac architecture, quit Dictionary, then replace the App in Applications.
Keep the previous download for rollback. No model, API key or system permission is bundled.

Only run one Dictionary App and enable one Dictionary Lookup extension at a time.
Updating the App does **not** reload an unpacked browser extension. Export/load the
matching extension, complete pairing yourself and confirm its shortcut before use.
Disable the old extension after switching; keep its folder until acceptance so you
can return to it. See the [guide](../guide.md) for setup and rollback instructions.

Service/model preferences and credential formats are unchanged. Ad-hoc upgrades may
require new selection consent; do not reset permissions routinely. Extension status
checks require App 0.3.0; when rolling back to App 0.2.0, use its matching extension.
Updates remain manual downloads and replacement, with no background installer.

## Scope of validation

Local tests cover capture/source stability, authenticated status requests with no model
side effects, export safety and packaging. Native Getting Started and sample preparation
were exercised; the owner completed an export whose eight files match the bundled payload.
Books and Session Manager river/finance queries, Markdown reading, Readest sentence
capture, and Edge extension river/finance queries have bounded acceptance evidence in
[reading compatibility](../reading-compatibility.md). This does not establish support
for every document, website, iframe, editing view, or AI meaning. Model-quality limits
remain in [quality validation](../quality.md).

The arm64 ZIP/DMG were built from `7e3404b`. Candidate CI passed Swift tests,
Node integration/packaging tests and release compilation. On a second Apple Silicon
Mac running macOS 27.2.1:

- Upgrading the existing 0.2.0 installation preserved the checked service/model
  preferences and retained an old-App backup for rollback.
- A real browser-downloaded DMG matched the candidate SHA-256 and retained the
  macOS quarantine attribute. The owner installed it and confirmed normal opening
  through the system's first-open flow.
- The installed executable and signature integrity matched the candidate. The owner
  confirmed the synthetic river original and contextual meaning, then exported the
  extension; all eight exported files match the installed App's bundled extension.

This was an existing-account upgrade with a prepared lookup environment, not a
clean-account installation, a new browser pairing test on that Mac, or proof of
context capture in every application. The agent changed no system permissions.
